# paulolo.com

A minimal personal landing page built with Next.js. A procedural ASCII ocean fills the viewport; the only controls link to LinkedIn and GitHub.

## Development

```bash
bun install
bun run dev
```

## Production

```bash
bun run build
bun run start
```

The page has no image assets, web fonts, or icon dependencies. It respects reduced-motion preferences and pauses its canvas renderer while the tab is hidden.
